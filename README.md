# MoveMate Emalahleni

Mobile-first prototype for a local moving and passenger transport marketplace serving Witbank / Emalahleni, Mpumalanga.

## Run
Open `index.html` in a modern browser. No build step is needed.

## Included
- Responsive customer landing and booking screen
- Separate moving-items and passenger-transport flows
- Vehicle suggestion based on load category or passenger count
- Clearly labelled demonstration price estimate

## Important prototype limitations
- No user accounts or database
- No real route distance: the current estimate uses a simulated value
- No driver dispatch, live GPS, notifications or payments
- No real bookings are transmitted
- All example rates are placeholders, not market prices or approved tariffs

## Before a public pilot
Connect a secure backend and authentication, a real routing/maps provider, driver onboarding and document review, dispatch and status updates, payment provider, admin-configured tariffs, privacy/security controls, and applicable South African transport licensing and insurance checks.
